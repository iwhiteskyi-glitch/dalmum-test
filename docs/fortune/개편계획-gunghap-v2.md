# 궁합 개편 계획 (2026-10-30 시작, 브랜치 feature/gunghap-v2)

오늘의 운세([개편계획-v2.md](개편계획-v2.md))·신년운세([개편계획-saeun-v2.md](개편계획-saeun-v2.md))·
내 사주([개편계획-saju-v2.md](개편계획-saju-v2.md))와 같은 방식으로 궁합(/gunghap)을 개편한다.

## 왜
지금 풀이 문장이 일간 관계 다섯 묶음(비겁·식상·재성·관성·인성)으로만 갈려서, 두 사람 일간 조합 100가지가
5가지 글로 모인다. 성별을 묻고, 용어(십신·일지) 설명이 그 자리에 없다.

## 사용자 결정 (2026-10-30)
1. 대표 표시: **점수 유지 + 점수 구성 보여 주기** — 계산식(gunghapScore) 그대로, 기본 53 + 오행 관계 + 음양 + 일지 + 채움을 줄로.
2. 보강 범위(넷 다) — 문장은 lib/fortune/gunghapTexts.json
   - ① **두 사람 맞춤 풀이 100개** `pairs[내 일간][상대 일간]` = {name(두 물상 이름), text}. 첫 문장에서 두 물상을 밝히고("큰 나무(갑목)인 나와 무쇠(경금)인 상대"), 둘째 문장 "~하듯"으로 뜻 풀기.
   - ② **영역별 궁합 40개** `areas.love|friend|family|work[내가 보는 상대의 십신 0~9]` — '가족' 새로.
   - ③ **잘 맞는 점·조심할 점·함께 하면 좋은 것** `points[십신]` = {good[3], care[3], together[3]}.
   - ④ **일지 조합별 풀이** `dayPairs["작은번호-큰번호"]` — 같은 글자 12·육합 6·반합 12·충 6 = 36개, 그 밖은 `dayNone` 하나.
3. 입력: **성별 대신 관계 고르기** — 연인·썸 / 친구 / 가족 / 일로 만난 사이 / 전부 보기. 고른 관계를 크게, 나머지는 접어서.
4. 공유: **남기기** — 공유 글·이미지 카드·링크를 새 내용으로. 링크는 `#g2.(나 일간).(나 일지).(상대 일간).(상대 일지).(나 오행).(상대 오행).(관계 0~4)`,
   예전 `#g1` 링크(영역 체크 3비트)도 계속 열림(한 영역만 골랐으면 그 관계, 아니면 전부 보기).

## 화면 (GunghapView.js, today.module.css 재사용 + gunghap.module.css)
결과 묶음("우리 궁합 결과") 안:
1. 짙은 코랄 판 — 두 사람 칩(태어난 날의 나/상대: 일간 + 일주), "상대는 나에게 ○○ 기운, 나는 상대에게 ○○ 기운" 한 줄,
   점수 고리 + 관계 이름 + 별, 맞춤 풀이(강조), 묶음 요약.
2. 점수는 이렇게 나왔어요 — 항목별 줄(기본·오행·음양·일지·채움).
3. ○○ 궁합(고른 관계) + "다른 사이로 보면" 접기.
4. 잘 맞는 점 · 조심할 점 · 함께 하면 좋은 것.
5. 태어난 날 아랫글자(일지) 궁합 — 두 글자와 조합 풀이.
6. 서로 다른 점·비슷한 점 — 오행 막대 + 서로 채워 주는 기운.
7. 결과 보내기(공유·링크 복사).
참고 정보(MoreInfo): 점수 설명 갱신, 성별 안 묻는 이유, 링크에 담기는 것(관계) 갱신.
정책(개인정보처리방침·FAQ·소개)의 궁합 "성별" 문구 갱신.
