## 사용자 결정 (2026-10-30, 전부 추천안 채택)
1. 대표 표시: **점수 없이 '한눈에 보는 나'** — 타고난 팔자에 점수를 매기지 않음.
   짙은 보라 판에 일주 이름(예: 병오일주)·큰 일간 글자·별칭·키워드·가장 많은/적은 오행·가장 많은 십신 묶음.
2. 보강 범위(넷 다) — 문장은 lib/fortune/sajuTexts.json
   - ① **일주 풀이 60개** `ilju[60갑자 번호]` — 태어난 날 두 글자(천간+지지)의 장면과 성격. 검색어 '○○일주' 대응.
   - ② **태어난 계절 풀이 40개** `season[일간][계절]` — 월지(절기 기준)로 봄(인묘진)·여름(사오미)·가을(신유술)·겨울(해자축). 조후(계절의 온도·습도로 보는 균형)를 쉽게.
   - ③ **십신 분포 + 풀이** `godGroups[5]` — 일간을 뺀 7글자(시간 모르면 5글자)를 비겁·식상·재성·관성·인성으로 세어 막대로.
     지지는 본기(정기) 천간으로 셈: 자계·축기·인갑·묘을·진무·사병·오정·미기·신경·유신·술무·해임. 묶음마다 뜻·많을 때(3개 이상)·없을 때.
   - ④ **영역별 성향** `areas[일간]`(연애·관계 / 일·적성 / 돈 쓰는 습관 / 생활 리듬, 40개) + **부족한 오행 채우기** `fill[오행]`(5개) —
     가장 적은 오행(같으면 나를 낳는 오행 → 나와 같은 → 내가 낳는 → 내가 이기는 → 나를 이기는 순)의 색·숫자·방향·맛·음식·장소(todayExtras.json lucky 재사용).
3. 공유: **빼기** — 친구에게 알려주기·링크 복사·공유 카드(buildSajuCard) 삭제. 예전 #j1 링크는 계속 열림(받는 쪽 유지).

## 화면 (SajuView.js, today.module.css 재사용 + saju.module.css)
