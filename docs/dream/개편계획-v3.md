# 꿈해몽 v3 개편 계획 (2026-10-29 시작, 브랜치 feature/dream-v3)

사용자 요청(2026-10-29): 사이트 전체를 유료 사이트에 뒤지지 않게 업그레이드(무료 서비스, 돈 드는 일 없이).
네이버 블로그 유입상 꿈해몽을 찾는 사람이 가장 많음 → **꿈해몽 먼저, 그다음 오늘의 운세**.

## 사용자 결정 (2026-10-29)
- 문장 검색: **브라우저 안 똑똑한 검색**(비슷한 말 사전 + 상황별 풀이 색인, 비용 0원). AI 모델·유료 API 안 씀.
- 그림 분위기: **밤하늘 금빛 선화**(짙은 남색 바탕 + 금색 가는 선). 사용자가 GPT 유료로 직접 생성.
- 그림 범위: **99장 전부**(상징마다 1장). 프롬프트는 docs/dream/그림프롬프트.md.
- 보강 글(꿈 15·여행 10국·6개국 name_note)은 개편과 별개로 main 공개 완료(7e2e2b7).
- 복잡한 작업은 Fable 모델도 사용 가능(사용자 안내).

## 1. 똑똑한 검색 (lib/dream/search.js 예정)
목표: "큰 뱀이 집에 들어와서 나를 물었어" → 뱀 꿈(뱀에게 물리는 꿈 장면) + 새집/집 관련 상징까지.
- 색인 대상: 상징 99개(label·keyword·짧은 해석) + 상세 페이지 상황별 풀이 제목 약 500개 + 자주 묻는 질문.
- 비슷한 말 사전(lib/dream/aliases.json): 이빨=치아=이, 시체=송장, 돈=현금=지폐, 바퀴벌레→벌레 등. 상징마다 사람들이 실제로 쓰는 말.
- 한국어 다듬기: 조사·어미 떼기(이/가/을/를/에서/했어/하는 꿈 등), 띄어쓰기 무시, 글자 2개씩 겹침(바이그램) 점수로 오타·변형 흡수.
- 결과: 상징 카드(그림 + 길흉 배지 + 한 줄 풀이) + "이 장면이 가장 비슷해요"(상황 제목, 상세 페이지 해당 위치로 이동) + 여러 상징이 잡히면 "한데 묶어 종합 해몽" 버튼(기존 종합 풀이 재사용).
- 편의: 자동 완성, 인기 검색어(서치 콘솔 상위), 최근 검색(이 브라우저에만 저장), 결과 없을 때 비슷한 꿈 추천.
- 개인정보: 검색어는 서버로 보내지 않음(브라우저 안에서만 처리). 검색 결과 화면은 색인 대상 아님(얇은 페이지 방지).

## 2. 디자인 (유료 앱 수준)
- 꿈해몽 첫 화면: 밤하늘 히어로 + 큰 검색창이 주인공. 그 아래 인기 꿈 그림 카드, 분류별 그림 타일, 기존 '장면 골라 종합 해몽'은 그대로 유지.
- 상세 페이지: 상단에 상징 그림 + 은은한 별 장식, 섹션 카드화, 비슷한 꿈 그림 카드.
- 그림 처리: 원본 PNG(docs/dream/그림원본/<id>.png) → 스크립트로 webp 변환(public/dream/art/<id>.webp, 512px·수십 KB), 화면에 보일 때만 불러오기. 그림이 아직 없는 상징은 분류 기본 장식으로 대체.
- 다크·라이트 모두 어울리게(그림 자체가 남색 카드라 어느 바탕에도 맞음).

## 3. 진행 순서
1. [완료] 그림 프롬프트 99개 전달 → 사용자 생성 완료(2026-10-29, 99장). webp 변환 완료(public/dream/art, 합계 4.2MB).
   - 61~80번(money~death) 20장은 세로 그림+양옆 빈 띠·색칠 그림체라 다시 그림(참고 그림 첨부 방식, 3차에 통과). 원본(174MB)은 git 제외.
2. [완료 2026-10-29] 검색 엔진 + 비슷한 말 사전 + 검사 스크립트(대표 문장 121개 전부 통과).
   - `lib/dream/search.js` — 엔진(순수 함수, JSON은 `createDreamSearch({symbols, aliases, titles})`로 주입). 자모 단위 비교,
     조사·어미 떼기, 한 글자 낱말(뱀·소·말·눈)은 어절 첫머리+조사일 때만, 같은 자리에선 긴 낱말 우선("말을 걸다" > "말").
   - `lib/dream/aliases.json` — 비슷한 말 사전(상징 99개 3,270항목, 동작·수식어 개념 87개, 오인 방지 목록). 상징·개념마다 한 줄.
     항목은 문자열 또는 `{t, kind(verb/mod/noun), w(점수), keep(긴 말 속 상징도 살림), start(어절 첫머리만)}`.
     한 글자 명사는 자동으로 0.6점, "뱀꿈"처럼 꿈이 붙으면 1점.
   - `lib/dream/searchData.js` — pages.json에서 상황 제목·FAQ 질문만 뽑아 클라이언트에 넘기는 서버용 도우미(본문은 안 보냄).
   - `scripts/dream/check-search.mjs` — 사전 무결성 + 대표 문장 121개(1등 상징·함께 나올 상징·나오면 안 될 상징·가장 비슷한 장면).
     `node scripts/dream/check-search.mjs "문장"`으로 낱말 분석·점수를 볼 수 있음(사전 다듬을 때).
   - 결과 구조: `{results:[{id, score, via, situations:[{index,title,score}], faq}], fallback, suggestions}`, `suggest(prefix)`는 자동 완성.
   - 속도(Node 기준): 색인 만들기 수십~200ms, 검색 1회 1ms 안팎 → 화면에서는 첫 입력 때 만들면 됨.
   - 한계: 부정("안 빠졌어")은 못 읽음. 띄어쓰기 없이 쓰면 한 글자 상징(뱀·소)은 놓칠 수 있음(두 글자 이상은 잡힘).
3. [완료 2026-10-29] 꿈해몽 첫 화면·결과 화면 디자인 개편
   - 첫 화면 순서: 밤하늘 히어로(큰 검색창·자동 완성·많이 찾는 꿈 칩·최근 검색) → 검색 결과 → 많이 찾는 꿈 그림 카드 8개
     → 장면 골라 종합 해몽(그림 칸 3~4열, 하나라도 고르면 아래에 붙는 해몽 버튼).
   - `components/dream/DreamSearch.js`(히어로+검색+결과), `DreamArt.js`(그림), DreamView는 상태(검색어·결과)만 묶음.
     검색 엔진·사전(약 80KB)은 검색창을 처음 누를 때 불러옴. 상황 제목은 서버에서 prop으로(searchData.js).
   - 검색 결과 카드: 그림·길흉·한 줄 풀이 + "이 장면이 가장 비슷해요"(1등이 뚜렷할 때만, 상세 페이지 `#s<번호>`로 이동)
     + "종합 해몽에 넣기"(상징 이름이 직접 나온 꿈은 미리 골라 둠) → 한데 묶어 기존 종합 풀이.
   - 결과 화면: 종합 흐름을 밤하늘 카드로, 상징별 카드에 그림. 상세 페이지 상황 항목에 id(s1, s2…)만 추가(디자인은 4단계).
   - 작은 그림 `public/dream/art/s/<id>.webp`(160px, 합계 약 0.7MB) — `node scripts/dream/art.mjs --thumbs`.
   - 최근 검색어 5개는 이 브라우저 localStorage에만(‘지우기’ 버튼), 개인정보처리방침 6항에 반영 — 사용자 확인 완료(2026-10-29, 유지).
   - 많이 찾는 꿈 목록은 짐작으로 고름 → 서치 콘솔에 꿈 검색어가 쌓이면 바꿀 것(DreamSearch.js POPULAR_QUERIES, DreamView.js POPULAR_IDS).
   - 사전 보강 후보: "호랭이" 같은 사투리는 못 찾음.
4. 그림 넣기(받는 대로) + 상세 페이지 디자인
5. 전체 검토 → 미리보기 → 사용자 확인 → main
6. 꿈 종류 늘리기(사용자 동의 2026-10-29): 99개 → 약 150개, **20~30개씩 2~3번 나눠** 추가.
   - 순서: 서치 콘솔·네이버에서 많이 찾는 꿈부터. 후보 예: 개구리·닭·벌·지렁이·늑대·여우·사자·코끼리·사슴·까치/까마귀·독수리·고래·게 / 강·호수·우물·동굴·해돋이·우박·얼음 / 부모님·형제자매·친구·선생님·경찰 / 손·발·눈동자·머리 감기 / 칼·가방·우산·책·편지·선물·케이크·술 / 키스·춤·노래·요리·청소·목욕·쇼핑·여행·면접·숨기·물건 잃어버리기. 병원·수술은 민감 상징 규칙(§7)으로.
   - 상징마다 짧은 해석 + 상세 페이지(1,200~1,800자) + 독립 검토 2명 + 그림 프롬프트(같은 스타일). 한꺼번에 찍어 내지 않음(틀에 찍은 페이지 방지).
   - id는 영어 소문자, 한번 정하면 바꾸지 않음(작성규칙 §9). 눈(snow)과 눈동자는 id·검색어 구분 주의.
7. 다음: 오늘의 운세 개편(별도 계획)
